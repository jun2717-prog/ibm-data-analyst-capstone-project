## English

The interactive dashboard for this project was built in **Google Looker Studio**, not exported as a static file. It contains three tabs:

1. **Current Technology Usage**
   Top 10 languages, databases, platforms, and web frameworks in use today.

2. **Future Technology Trends**
   Top 10 languages, databases, platforms, and frameworks desired for next year.

3. **Demographics**
   Respondent breakdown by age, country, and education level.

### Screenshots

Add screenshots of each tab to this folder (e.g. `current-technology-usage.png`, `future-technology-trends.png`, `demographics.png`) and reference them from the main `README.md`.

### Data Sources

The dashboard reads from the top-10 ranking CSVs generated by `scripts/05_top10_rankings_export.py`, plus the raw survey dataset directly for the Demographics tab (Age, Country, EdLevel columns).

## 日本語

本プロジェクトのダッシュボードは **Google Looker Studio** で作成しており、静的ファイルとしては書き出していません。以下の3タブで構成されています。

1. **現在の技術利用状況**
   現在使われている言語・データベース・プラットフォーム・Webフレームワークの上位10件。

2. **将来の技術トレンド**
   来年求められる言語・データベース・プラットフォーム・フレームワークの上位10件。

3. **回答者属性**
   年齢・国・学歴による回答者の内訳。

### スクリーンショット

各タブのスクリーンショットをこのフォルダに追加してください（例: `current-technology-usage.png`、`future-technology-trends.png`、`demographics.png`）。ルートの `README.md` から参照する想定です。

### 使用データ

ダッシュボードは `scripts/05_top10_rankings_export.py` が出力するトップ10ランキングCSV、および属性タブについては調査データの生データ（Age・Country・EdLevel列）を直接参照しています。
